# Project Module 2 – Password Cracking with Networkwalks Tools

## 🎯 Objective

The objective of this lab was to recover the password of an authorized password-protected PDF using Networkwalks Hash Calculator and Password Cracker.

## 🛠️ Tools

- Web Browser
- Networkwalks Hash Calculator
- Networkwalks Password Cracker
- Windows / Kali Linux

## 🔄 Methodology

1. Obtain the authorized password-protected PDF -see in the screenshots directory -
2. Upload the PDF to the Networkwalks Hash Calculator using this link: https://networkwalks.com/hash-calculator/
3. Extract the complete PDF hash.
4. Copy the hash value.
5. Open the Password Cracker using the link: https://networkwalks.com/password-cracker/
6. Paste the hash.
7. Start the password-cracking process.
8. Recover the password.
9. Use the recovered password to unlock the PDF.

## 🧠 What I Learned

- How a protected PDF can be represented by a password hash.
- How hash extraction works.
- How password-cracking tools test possible password candidates.
- How password complexity affects cracking time.
- Why strong passwords are essential for protecting sensitive files.
